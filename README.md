# LiveLec

## Описание проекта

LiveLec — это платформа для проведения интерактивных лекций в реальном времени. 

Сервис объединяет трансляцию презентаций, сбор вопросов от слушателей, проведение блиц-опросов и замер вовлеченности аудитории. Уникальной особенностью является встроенное распознавание речи (ASR), которое "на лету" генерирует субтитры для студентов и формирует итоговый текстовый конспект лекции.

## Цель проекта

- Улучшить взаимодействие между преподавателем и студентами во время занятий.
- Дать студентам безопасный инструмент для обратной связи (анонимные вопросы, кнопка "Я не понимаю").
- Снизить рутинную нагрузку с помощью автоматической расшифровки речи нейросетью.
- Предоставить подробную аналитику для оценки качества проведенных лекций.

## Целевая аудитория

- **Преподаватели и лекторы**, желающие получать моментальный фидбек и контролировать внимание аудитории.
- **Студенты и слушатели вебинаров**, которым важно активно участвовать в занятии, видеть субтитры и не бояться задавать вопросы.
- **Учебные заведения**, внедряющие цифровые инструменты в образовательный процесс.

## Основной функционал

### Интерактивная лекционная комната
- Быстрое подключение слушателей по 6-значному PIN-коду (без регистрации).
- Загрузка презентаций (PDF, PPTX) и синхронный показ слайдов на устройствах студентов.
- Отображение количества активных участников в реальном времени.

### Живая обратная связь
- Чат для анонимных вопросов студентов с системой "лайков" (сортировка по популярности).
- Индикатор "Я не понимаю" (Confusion button) с защитой от спама для замеров сложности материала.

### Инструменты преподавателя
- **Распознавание речи (ASR)**: Локальная нейросеть (Whisper) переводит голос в текст, транслируя субтитры слушателям.
- **Блиц-опросы (Live Quizzes)**: Создание быстрых тестов с таймером и отображением статистики ответов в виде прогресс-баров.
- Личный кабинет с управлением дисциплинами и настройками профиля.

### Аналитика и экспорт
- Глобальная статистика (рост вовлеченности, всего лекций, охват).
- Детальный отчет по каждой лекции: тепловая карта (Heatmap) непонимания по минутам.
- Скачивание текстовой расшифровки (транскрипта) лекции в форматах `.txt` и `.md`.

## Роли пользователей

- **Студент (Гость)** — подключение по PIN, просмотр слайдов и субтитров, отправка вопросов, участие в опросах, использование кнопки "Не понимаю".
- **Преподаватель** — регистрация/авторизация, управление лекциями и презентациями, запуск опросов и ASR, доступ к аналитике и архиву.

## Архитектура проекта

- **Frontend**: SPA на React, сборка через Vite, стилизация Tailwind CSS.
- **Backend**: Асинхронный REST API и WebSockets сервер на FastAPI (Python).
- **База данных**: PostgreSQL (взаимодействие через SQLAlchemy + asyncpg).
- **Инфраструктура и сеть**: 
  - Nginx в качестве реверс-прокси и веб-сервера для раздачи статики.
  - Двусторонний обмен данными реализован через WebSockets (статусы, чат, слайды, субтитры).
- **Внешние зависимости (внутри контейнера)**:
  - `faster-whisper` для распознавания речи.
  - LibreOffice и PyMuPDF для конвертации загружаемых PPTX/PDF презентаций в изображения слайдов.

## Запуск проекта

### 1. Предварительные требования

- Docker
- Docker Compose

### 2. Клонирование репозитория

Склонируйте репозиторий на локальную машину:
    
    git clone <url-вашего-репозитория>
    cd LiveLec

### 3. Настройка окружения

В проекте уже заданы базовые настройки в `server/app/core/config.py`, но для Production среды рекомендуется создать файл `.env` в директории `server` (на основе конфигурации) и переопределить следующие переменные:

- `DATABASE_URL` (например, `postgresql+asyncpg://user:password@db:5432/app`)
- `SECRET_KEY` (секрет для подписи JWT-токенов)
- `WHISPER_MODEL` (размер модели распознавания, по умолчанию `small`)

### 4. Запуск контейнеров

Запустите сборку и старт всех сервисов через Docker Compose:

    docker-compose up --build -d

После успешной сборки и старта:
- **Веб-интерфейс**: будет доступен по адресу `http://localhost:3000`
- **Backend API**: проксируется через Nginx, прямой доступ к Swagger UI: `http://localhost:8000/docs`

## Получение секретов и ключей

### JWT_SECRET
Для генерации безопасного ключа аутентификации можно воспользоваться OpenSSL:

    openssl rand -hex 32

Вставьте полученный хэш в переменную `SECRET_KEY` конфигурации бэкенда для безопасной генерации токенов сессий преподавателей.

### Пароль к PostgreSQL
Пароли и доступы к БД задаются в `docker-compose.yml` в блоке `environment` сервиса `db`. Убедитесь, что переменные `POSTGRES_USER`, `POSTGRES_PASSWORD` и `POSTGRES_DB` совпадают со строкой подключения `DATABASE_URL` в бэкенде.
